## 🌌 Proje Hakkında

**Kuantizma**, kuantum fiziğinin temel kavramlarını Türkçe olarak keşfetmeni sağlayan interaktif bir web sitesidir. Süperpozisyondan kuantum dolanıklığına, Schrödinger'in Kedisi'nden Planck sabiti'ne kadar pek çok konuyu kapsayan zengin içerik sunar.

---

## ✨ Özellikler

| Özellik | Açıklama |
|---|---|
| 🔐 **Giriş Sistemi** | Şık glassmorphism tasarımlı login ekranı |
| ⚛️ **10 Kuantum Kartı** | Tıklanabilir, detaylı açıklama modalları |
| 📚 **10 Konu** | Kuantum mekaniğinin tüm dalları |
| 📱 **Tam Mobil Uyumlu** | Her ekran boyutuna uyarlanmış tasarım |

| 💫 **Animasyonlar** | Akıcı hover & modal animasyonları |
